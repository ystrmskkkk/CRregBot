# CRregBot

Telegram-бот для турниров по Clash Royale. Он принимает регистрацию, проверяет готовность игроков, строит сетку на выбывание, собирает результаты матчей и объявляет чемпиона. Всё происходит в Telegram, без таблиц и ручных жеребьёвок.

Написан на Python с [aiogram 3](https://docs.aiogram.dev/), данные хранятся в SQLite.

## Возможности

- **Регистрация в пару нажатий.** Игрок жмёт кнопку, и бот спрашивает ник в Clash Royale. Попасть в бота можно и кнопкой «Зарегистрироваться» из поста в канале: ссылка вида `t.me/<бот>?start=register` сразу открывает регистрацию.
- **Проверка готовности.** Перед стартом сетки и перед каждым раундом игроки подтверждают готовность кнопкой. Кто не успел, тот снимается с турнира до сетки или получает техническое поражение в матче.
- **Сетка на выбывание (single elimination).** Жеребьёвка случайная. Если участников не степень двойки, бот сам раздаёт «баи», то есть проходы без матча.
- **Автоматические раунды.** Админ вносит результат кнопкой под матчем, а бот сам формирует следующий раунд и в конце объявляет чемпиона, в том числе в канале.
- **Лобби матча.** Игрок присылает ссылку на Дружеский бой, и бот пересылает её сопернику.
- **Статистика игрока** по всем турнирам.
- **Панель с кнопками.** Отдельное меню для участников и для админов, админские команды скрыты от обычных пользователей.
- **Ограничение числа участников** и настраиваемый таймаут готовности.

## Как проходит турнир

1. Админ создаёт турнир, и открывается регистрация.
2. Игроки регистрируются в боте или через кнопку в посте канала.
3. Админ закрывает набор, и бот запускает проверку готовности.
4. Бот строит сетку, раздаёт баи и сообщает игрокам их пары.
5. Игроки создают лобби и играют, админ отмечает победителя.
6. После каждого раунда следует новая проверка готовности и новый раунд, пока не определится чемпион.

## Команды

**Для всех:**

| Команда | Что делает |
| --- | --- |
| `/start`, `/menu` | Открыть меню с кнопками |
| `/register` | Зарегистрироваться (бот спросит ник) |
| `/unregister` | Отменить регистрацию, пока набор открыт |
| `/participants` | Список участников |
| `/bracket` | Текущая сетка |
| `/my_stats` | Личная статистика |
| `/lobby <id_матча> <ссылка>` | Отправить сопернику ссылку на Дружеский бой |
| `/help` | Справка |

**Для админов** (их Telegram ID указываются в `ADMIN_IDS`):

| Команда | Что делает |
| --- | --- |
| `/admin` | Открыть админ-панель |
| `/new_tournament [название]` | Создать турнир и открыть регистрацию |
| `/start_bracket` | Закрыть регистрацию и запустить проверку готовности |
| `/result <id_матча> <1\|2>` | Внести результат вручную |
| `/force_ready_check` | Завершить проверку готовности, не дожидаясь таймаута |
| `/end_tournament` | Досрочно завершить турнир |
| `/announce_channel <@канал> <текст>` | Опубликовать пост с кнопкой регистрации |

## Структура проекта

| Файл | Зачем |
| --- | --- |
| `bot.py` | Обработчики команд и кнопок, логика турнира, проверка готовности |
| `bracket.py` | Жеребьёвка, баи и построение раундов |
| `database.py` | Работа с SQLite: турниры, участники, матчи, лобби, проверки готовности |
| `config.py` | Чтение настроек из `.env` |
| `.env.example` | Шаблон настроек |

## Установка

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/ystrmskkkk/CRregBot.git
cd CRregBot
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и заполни:

| Переменная | Обязательна | Что это |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен от [@BotFather](https://t.me/BotFather) |
| `BOT_USERNAME` | для кнопки в канале | Username бота без @ |
| `ADMIN_IDS` | да | ID админов через запятую (узнать — [@userinfobot](https://t.me/userinfobot)) |
| `CHANNEL_USERNAME` | нет | Канал для объявления чемпиона |
| `MAX_PARTICIPANTS` | нет | Лимит участников, 0 — без лимита |
| `READINESS_TIMEOUT_MINUTES` | нет | Минут на подтверждение готовности, 0 — отключить проверку |
| `DB_PATH` | нет | Путь к файлу базы, по умолчанию `tournament.db` |

Запуск:

```bash
python bot.py
```

Бот работает через long polling: домен и вебхук не нужны, достаточно, чтобы процесс был запущен. Для работы круглосуточно подойдёт недорогой VPS с systemd-сервисом и `Restart=always`.
